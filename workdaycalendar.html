Workday to Google Calendar Automation

Using Google Gemini, I iterated a Python script that takes my exported Workday classes, and converts them into an iCalendar file that can be uploaded to Google Calendar. I also prompted it to create a user interface that simply prompts the user for the classes it will include in the calendar file.

When prompting the chatbot, in order to get the most effective result, I first prompted it to make a plan of how to accomplish the given task. This is when it suggested a Python script and justified why this would be the best approach. As I continued the thread, I made manual changes to the code and began to get more familiar with the basics of Python.

From this experience, I learned the value of using AI assistants to expedite simple tasks, and how to give clear instructions to ensure my desired output. Despite being unfamiliar with Python going into this project, I was able to use AI to my advantage to use the language regardless. While I advocate for AI integration to help with certain tasks, it is very important to me that it is not used to fully remove humans from the design process. I used Gemini in this project to deepen my understanding of Python and to learn how to use AI efficiently. I also made sure to read through the code to get a sense of how each section was contributing. I look forward to further investigating AI and human integration in the future.
